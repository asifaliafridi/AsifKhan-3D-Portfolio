# Asif Khan — 3D Portfolio

A modern personal portfolio built with React, Vite, Three.js and React Three Fiber.

## Highlights
- Interactive Three.js hero scene
- Responsive dark visual system
- Portfolio filtering (All / Web / App / Design)
- Existing Asif Khan portfolio projects and profile content
- CV, Behance, LinkedIn and GitHub links
- Mobile-friendly layout

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
